# Fortune Cookie Funnies for Engineers

A one-line fortune-cookie message for a software engineer (104 characters):

> Your lucky numbers are 404, 500, and the 83 tests you skipped, which just passed themselves without you.

The entry program (`main.py`) writes the fortune to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` (default `/output`).
